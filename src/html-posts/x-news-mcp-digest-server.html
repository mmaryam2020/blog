X-News: An MCP server that turns X threads into blog digests

Automating thread ingestion, insight extraction, and publication with Model Context Protocol and a companion Monster Squad.

Following technical discussions on X often means spending twenty minutes scrolling through noise to find a few minutes of substantive information. Developer mmaryam2020 built X-News to automate that workflow. It is a Model Context Protocol (MCP) server that converts X posts or threads into standalone HTML digests published directly to a blog.

How it works

The pipeline operates in three distinct stages:

1
Ingestion

Playwright launches Chrome and extracts the author profile, full text, and engagement metrics directly from the post.

2
Synthesis

The pipeline infers a title, slug, tags, and category, pulls out key takeaways, and formats a self-contained HTML page.

3
Publication

The output writes directly to the local blog repository, where it is immediately ready for local preview and deployment.

Available MCP tools

X-News exposes five tools over the standard MCP protocol, allowing clients like Claude Desktop, Cursor, and Antigravity to trigger actions on demand:

Tool Name Description
digest_x_post Runs the full pipeline from raw URL to published HTML digest in one shot.
get_x_post Scrapes and returns structured metadata and body text for a single post.
get_x_bookmarks Fetches recent bookmarks saved to the authenticated account.
search_x Executes search queries and collects matching post payloads.
summarize_x_topics Aggregates and synthesizes top discussion themes across posts.

Technical implementation

The server is written in TypeScript and uses Playwright for browser automation. Authentication relies on a persistent session created during an initial manual login in Chrome. This eliminates the need to store passwords in configuration files.

To run the pipeline locally:

# Clone and install dependencies
git clone https://github.com/mmaryam2020/x-news.git
cd x-news
npm install

# Authenticate once in Chrome
npm run auth

# Ingest and publish a digest in one command
npm run digest "https://x.com/username/status/1234567890"
Exposing this pipeline over MCP makes it accessible to desktop assistants like Claude Desktop, Cursor, or Antigravity, turning multi-step thread reading into an automated background action.
